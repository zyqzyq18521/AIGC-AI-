电影感的核心，是光影与背景

电影感不是加个滤镜那么简单。它来自明暗关系、色温情绪、景深层次和视觉焦点的共同作用。光影决定人物立不立体、情绪是温暖还是冷峻；背景决定故事发生在哪里、人物与环境的张力如何。普通拍摄常遇到三个问题：现场光线不可控，背景杂乱难避开，后期调色找不到方向。AI 的价值，不是替你按快门，而是帮你在已有素材上重新设计光影与背景，把“记录”变成“创作”。

AI 优化光影：从平光到戏剧光

训练营首先教你用 AI 重塑光影。它不是简单提亮或压暗，而是理解光源方向、明暗过渡和色温关系。你可以让平淡的顺光变成侧逆光，为人像勾出轮廓；可以把正午硬光改成黄昏柔光，让皮肤更通透；也可以模拟霓虹夜景、窗边自然光、顶光戏剧感。关键是保持皮肤质感，避免塑料感和过度磨皮。AI 负责计算光影分布，你负责判断情绪方向。一张有电影感的人像，光一定在讲故事。

AI 重塑背景：让环境服务人物

背景是人像的第二个主角。AIGC 可以智能识别主体，分离背景，再生成符合叙事的环境。但训练营强调：换背景不是随便换。要根据人物情绪、服装、色调和光线方向匹配场景。穿风衣站在雨夜街头，和穿白裙站在海边黄昏，需要完全不同的光影与色彩。AI 还能做景深虚化、光斑、颗粒、雾气等氛围元素，让背景既有细节又不抢戏。好的背景，是让人物更突出，而不是更花哨。

从单张到系列：建立风格模板

一张大片靠灵感，一组大片靠系统。训练营会教你建立自己的风格模板：统一色调、统一光影逻辑、统一构图倾向。这样无论是日常更新还是商业拍摄，都能保持辨识度。AI 可以批量处理，提高产能，但审美标准必须由你把控。电影感不是随机生成，而是持续输出同一种情绪。
